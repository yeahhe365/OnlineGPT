## Overview

A Python and PyQt5 desktop search assistant that uses Google, Bing, Baidu, and other engines to provide live web context for language models.

## Features

- Graphical search interface.
- Supports multiple search engines.
- Fetches keyword-related web content for language-model workflows.
- Designed for local desktop use.

## Quick Start

- Prepare a Python runtime.
- Enter the `OnlineGPT` directory.
- Install the dependencies required by the source code, then run `python main.py`.

## Configuration

- Configure search, language, and advanced options in the desktop UI.

## Tech Stack

- Python
- PyQt5
- Google/Bing/Baidu search
